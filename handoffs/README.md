# Agent Handoffs

This folder stores concise, tool-agnostic handoffs for Codex and other agentic coding tools.

Rules:
- Keep one timestamped note per major work session.
- Update `CURRENT.md` with the latest active handoff.
- Use the sections from `TEMPLATE.md`.
- Prefer outcome/status/next-steps over raw changelogs.
- Include live verification commands when relevant.
