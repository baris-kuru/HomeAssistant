# Agentic Lab

This folder is a lightweight playground for cross-tool experiments around Persona and the surrounding agentic tooling.

Use it for:
- testing workflow ideas before baking them into the main product
- comparing OpenCode, Codex, Claude Code, and OpenClaw behaviors
- writing short notes about prompt patterns, agent roles, and plugin experiments
- keeping throwaway docs or prototypes separate from the production app

Suggested structure:
- `notes/` for observations and learnings
- `workflows/` for prompt drafts and command patterns
- `experiments/` for temporary code or prototypes

Current workspace roots:
- Persona App: the main HomeAssistant/Persona codebase
- Agentic Lab: your experimental agentic project area
- OpenCode Config: global OpenCode agents, commands, and config
- OpenClaw: HomeBot/OpenClaw config and flows
- Codex: Codex config, skills, plugins, and session state
- Claude Code: Claude Code settings and local state
